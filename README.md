# Ponte

Un défi de langue par jour, en quelques minutes : un article court le matin, un petit oral le soir. Portugais du Portugal d'abord, puis russe et arabe.

Ouvrir l'appli : https://ben-shelby.github.io/ponte/
Sur iPhone : ouvrir le lien dans Safari, puis Partager, « Sur l'écran d'accueil ».

- Les articles sont préparés chaque semaine par une routine Claude, à partir de l'actualité (énergie, IA, géopolitique, business) en semaine et de la vie quotidienne le week-end.
- La progression reste sur le téléphone. Rien n'est envoyé ailleurs.
- Aucun coût : site statique sur GitHub Pages, pas d'API payante.
